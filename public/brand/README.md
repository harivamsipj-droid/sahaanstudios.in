# Sahaan Studios logo assets

## Current website logo

The approved logo is assembled from the user-supplied 4K symbol and SAHAAN STUDIOS wordmark in `three-parts/`. The website loads smaller, lossless PNG copies from `web/` (264px symbol, 760px wordmark, 1240px tagline), generated by `scripts/build-logo-assets.ps1`. These dimensions provide roughly 2–4 device pixels per displayed pixel without shipping the 4K artwork to every visitor. The tagline is displayed in the desktop footer; on narrow screens, its wording remains accessible as text. The pale source backgrounds are blended into the site surfaces, so the art is not shown inside separate white cards.

The folder contains the original PNGs and web-optimized WebP versions. Keep the source artwork intact. Update `app/globals.css`, `public/desktop/index.html`, and `public/mobile/mobile.html` together for future logo changes.

## Site icon

`sahaan-studios-final-icon.png` is the square crop of the approved emblem used as the favicon. All other earlier logo variants were removed; they can be recovered from Git history if ever needed.

Verify `app/globals.css`, `public/desktop/index.html`, and `public/mobile/mobile.html` at phone and desktop widths after any logo update.
